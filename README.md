# 🔤 Coding Symbols & Brackets Glossary

A comprehensive, searchable reference guide for programming symbols, brackets, and operators with their correct English names and usage contexts.

## 🌐 Live Demo

**[View Live Site](https://ukccatc.github.io/brackets-and-symbols/)**

## ✨ Features

- 🔍 **Live Search & Filter** - Instantly find any symbol or term
- 📋 **One-Click Copy** - Copy any symbol to clipboard with a single click
- 🎨 **Dark/Light Mode** - Automatic theme detection with manual toggle
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- ♿ **Accessible** - Semantic HTML, ARIA labels, keyboard navigation
- 🚀 **Fast & Lightweight** - Pure HTML/CSS/JS with Tailwind CDN

## 📚 Content Categories

- **Brackets Family** - (), [], {}, <>, ||
- **Quotes & Strings** - ", ', `, apostrophe
- **Math & Logic Operators** - +, -, *, /, %, ^, **, ==, ===, &&, ||, !, ?:, =>, etc.
- **Delimiters & Punctuation** - :, ;, ,, ., ..., #, @, _, ~, \, |, &
- **Common Phrases** - "opening bracket", "brace-delimited block", "parenthesized expression"
- **Important Notes** - Common mistakes and ambiguous terminology

## 🚀 Local Development

No build process required! Simply open the HTML file:

```bash
# Clone the repository
git clone https://github.com/ukccatc/brackets-and-symbols.git
cd brackets-and-symbols

# Open in browser
open index.html
# or
python3 -m http.server 8000  # then visit http://localhost:8000
```
